# ВКР 2026: ценообразование на нефтегазовых рынках России и Азербайджана

**Тема:** «Особенности и перспективы изменения ценообразования на нефтегазовых
рынках (на примере России и Азербайджана)».

Работа собирается в виде двух самостоятельных файлов.

| Файл | Что внутри | Объём |
|---|---|---|
| `out/VKR_2026_Glava_1_Teoriya.docx` | титул, содержание, введение, глава 1, список источников (29) | 24 с., глава 1 — 16 с. из 20 |
| `out/VKR_2026_Ekonometricheskaya_model.docx` | единственная эконометрическая модель на годовой панели 2018—2025 гг.: идея, данные и источники, уравнение с раздельными блоками России и Азербайджана, диагностика, результаты, проверка контрактных параметров, перевод в деньги и связь с главами 2 и 3, инструменты | 20 с., 7 таблиц, 16 источников, 12 сносок |

## Порядок сборки

```bash
python3 analysis.py         # out/metrics.json  — реестр исходных показателей
python3 model.py            # out/model.json    — оценки модели
python3 build_ch1.py        # документ 1 (теория) + отчёт по страницам
python3 build_model_doc.py  # документ 2 (модель)
python3 verify_docs.py      # сверка чисел и источников в обоих документах
```

Зависимости: `python-docx`, `pandas`, `numpy`, `statsmodels`, `scipy`,
`matplotlib` (только для полной версии работы).

## Оформление (документ 1)

- Times New Roman 14 пт, полуторный интервал, отступ 1,25 см, поля 3,0 / 1,5 /
  2,0 / 2,0 см, выравнивание по ширине;
- титул и содержание — без номера страницы; страница с введением — третья,
  далее сквозная нумерация внизу по центру;
- заголовки глав — по центру, полужирным, ЗАГЛАВНЫМИ, с новой страницы;
  параграфы — с абзацного отступа, строчными;
- ссылки на источники — подстрочные сноски 10 пт (настоящие сноски Word);
  список источников — по ГОСТ Р 7.0.100-2018, 29 позиций;
- таблица: «Таблица N.» справа, заголовок по центру, источник под таблицей;
- формулы — по центру, номер в круглых скобках у правого края, расшифровка
  «где …» с новой строки.

Объём главы 1 считается отдельно (`build_ch1.py` печатает «страниц в главе 1»):
16 страниц при лимите 20. Список источников в лимит не входит.

## Модель (документ 2)

```
P_it = a + b_AZ·(Brent_t·AZ_i) + b_RU·(Brent_t·RU_i) + c_RU·RU_i
       + d_S·SANCTIONS_it + d_C·CAP_it + d_B·(BUDGET_it − Brent_t) + u_it
```

Одна модель на годовой сбалансированной панели «страна — год» (2018—2025 гг.,
16 наблюдений). У каждой страны свой блок: российский описывает контрактный
режим (санкции 2022 г. и потолок цен с 2023 г.), азербайджанский — контрактный
ориентир (бюджетная цена нефти). Brent остаётся общей мировой составляющей.

- зависимая переменная — среднегодовая цена экспорта, долл./барр. (Urals для
  России, Azeri Light CIF для Азербайджана);
- adjR² 0,986, F 2 490, σ 1,74 долл./барр., средняя относительная ошибка 1,2 %;
- bAZ = 1,038 (0,037), bRU = 0,922 (0,056) — обе цены привязаны к Brent
  практически один к одному;
- dS = −20,8 долл./барр. (p < 0,001), dC = −13,1 долл./барр. (p < 0,001);
  сумма −33,9 долл./барр. — институциональная составляющая дифференциала;
- d_B = 0,021 (p 0,54): бюджетная цена — ориентир, а не ценообразующий фактор;
- структурный сдвиг: сдвиг российской ветви F = 30,3 (p < 0,001), сдвига
  азербайджанской ветви нет (F = 1,03, p 0,37); граница сдвига — 2022 г.;
- устойчивость: без 2022 г. dC = −13,08, по российской ветви 2013—2025 гг.
  (13 наблюдений) dC = −14,00, без бюджетного ориентира dC = −13,08,
  jackknife −14,24…−11,73; тест на ложную дату максимален на 2023 г.;
- контрактная проверка: премия Azeri Light постоянна (2,14 долл./барр.,
  тренд p 0,81), эластичность экспорта по цене у России 0,049 (p 0,67),
  у Азербайджана −0,19; 73 % падения выручки России даёт цена,
  92 % падения выручки Азербайджана — объём;
- пересчёт в деньги (формула (2) документа): L = |dC|·Q·7,33/1000 — при
  экспорте 238 млн т потери 24,9 млрд долл. = 2,30 трлн руб. = 27 % 
  нефтегазовых доходов бюджета 2025 г.; каждый доллар скидки — 1,74 млрд долл.
  (160,8 млрд руб.).

Все числа в тексте документа формируются из `out/model.json`; ручных цифр нет,
поэтому `verify_docs.py` проверяет документ целиком.

## Данные

- `data/panel_annual.csv` — годовая панель «страна — год» (21 строка,
  2013—2025 гг.): `year, country, price, brent, q_export_mt, cap, cap_level,
  budget_price, profit_share, notes`. В модель входят 2018—2025 гг.
  (16 наблюдений); российская ветвь 2013—2017 гг. используется для проверки
  устойчивости.
- Ряды цен: Urals — Минфин России (2013—2024) и итог 2025 г.;
  Azeri Light — SOCAR / Минфин / ЦБ Азербайджана (2018—2025); Brent —
  `data/brent-monthly.csv` (github.com/datasets/oil-prices), среднегодовые.
- `facts_panel.py` — фактические значения (цены, объёмы экспорта, бюджетные
  цены, потолки, параметры контрактов «Роснефть» — CNPC и АЧГ) с привязкой к
  ключу источника.
- Каждая цифра панели имеет подстрочную сноску в документе 2.

## Проверки

```bash
python3 verify_docs.py                        # числа + источники, ожидаемый итог «ок»
DETAIL=1 python3 verify_layout.py out/*.docx  # разбивка по страницам
```

`verify_docs.py` печатает список источников реестра, которые не процитированы в
документе 1: это нормально — часть из них (методы оценивания, источники данных)
используется только в документе 2.
