# ВКР 2026: ценообразование на нефтегазовых рынках России и Азербайджана

Черновик выпускной квалификационной работы (бакалавриат).

**Тема:** «Особенности и перспективы изменения ценообразования на нефтегазовых
рынках (на примере России и Азербайджана)».

**Итоговый файл:** `out/VKR_2026_Tsenoobrazovanie_neftegaz_Rossiya_Azerbaijan.docx`

## Что внутри

| Файл | Назначение |
|---|---|
| `facts.py` | исходные данные: значения с указанием единицы измерения и источника |
| `analysis.py` | расчёт производных показателей → `out/metrics.json` |
| `sources.py` | 52 источника в порядке ГОСТ, `check_alphabet()` |
| `fmt.py` | типографика чисел: `n`, `pct`, `usd`, `mult`, неразрывные пробелы |
| `docx_engine.py` | класс `VKR`: абзацы, заголовки, таблицы, рисунки, формулы, оглавление |
| `build_figures.py` | 6 рисунков в `figures/` (matplotlib) |
| `text_ch1.py` | глава 1 (разделы 1.1, 1.2), формулы (1)–(2), таблица 1 |
| `text_ch2.py` | глава 2 (разделы 2.1, 2.2), рисунки 1–5, таблица 2 |
| `text_ch3.py` | глава 3 (разделы 3.1, 3.2), таблица 3, рисунок 6 |
| `text_front.py` | титул, введение, заключение, приложение А, список литературы |
| `build_docx.py` | сборка документа, подстановка ссылок, отчёт по объёму |
| `verify_numbers.py` | сверка каждой цифры текста с `out/metrics.json` |
| `verify_layout.py` | оценка числа страниц по метрикам шрифта |

## Порядок сборки

```bash
cd research/vkr_oil_gas_pricing_2026
python3 analysis.py        # out/metrics.json
python3 build_figures.py   # figures/*.png
python3 build_docx.py      # out/VKR_...docx + out/blocks.json
```

Проверки (необязательно, но полезно перед сдачей):

```bash
python3 verify_numbers.py   # 0 нераспознанных токенов = все цифры прослеживаются
python3 verify_layout.py    # оценка числа страниц
```

`build_docx.py` завершается с ошибкой, если в тексте встретился ключ источника,
отсутствующий в `sources.py`, или если в списке литературы остался
непроцитированный источник.

## Оформление

- Times New Roman 14 пт, полуторный интервал, абзацный отступ 1,25 см;
- поля: левое 3,0 см, правое 1,5 см, верхнее и нижнее 2,0 см;
- выравнивание по ширине, заголовки разделов — с новой страницы;
- нумерация страниц — внизу по центру, титульный лист без номера;
- таблицы и рисунки с подписями по ГОСТ (подпись над таблицей, под рисунком);
- библиографические ссылки в тексте — `[n]`, список по ГОСТ Р 7.0.100-2018.

## Особенности реализации

- Каждая цифра в тексте берётся из `out/metrics.json`; «ручных» чисел в текстах
  глав нет, поэтому `verify_numbers.py` может проверить всю работу целиком.
- Ссылки на источники в исходниках пишутся как `[@@ключ]`, при сборке
  заменяются на порядковый номер в списке литературы.
- Номера страниц в содержании рассчитываются до сохранения документа
  (`verify_layout.page_map`) и подставляются в строки оглавления; при
  необходимости их можно обновить вручную после правок вёрстки.
- Оглавление оформлено как поле `TOC`: после открытия в Word его можно
  обновить (Ctrl+A, F9), чтобы получить автоматические номера страниц.
- Титульный лист содержит плейсхолдеры `[...]` — их нужно заменить на данные
  вуза, кафедры, автора и научного руководителя.

## Объём

Около 79 тыс. знаков основного текста; по расчёту вёрстки — примерно 67 страниц,
из них основная часть (введение, главы, заключение) — около 55 страниц,
список литературы и приложение — остальное. 52 источника, все процитированы.
