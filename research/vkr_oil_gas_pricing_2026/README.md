# ВКР 2026: ценообразование на нефтегазовых рынках России и Азербайджана

**Тема:** «Особенности и перспективы изменения ценообразования на нефтегазовых
рынках (на примере России и Азербайджана)».

Работа собирается в виде двух самостоятельных файлов.

| Файл | Что внутри | Объём |
|---|---|---|
| `out/VKR_2026_Glava_1_Teoriya.docx` | титул, содержание, введение, глава 1, список источников (29) | 24 с., глава 1 — 16 с. из 20 |
| `out/VKR_2026_Ekonometricheskaya_model.docx` | единственная эконометрическая модель «до и после»: идея, данные и источники, уравнение и правила расчёта, диагностика, результаты, перевод в деньги и связь с главами 2 и 3, инструменты | 14 с., 5 таблиц, 13 источников, 11 сносок |

## Порядок сборки

```bash
python3 analysis.py         # out/metrics.json  — реестр исходных показателей
python3 model.py            # out/model.json    — оценки модели
python3 build_ch1.py        # документ 1 (теория) + отчёт по страницам
python3 build_model_doc.py  # документ 2 (модель)
python3 verify_docs.py      # сверка чисел и источников в обоих документах
```

Зависимости: `python-docx`, `pandas`, `numpy`, `statsmodels`, `scipy`,
`matplotlib` (только для полной версии работы).

## Оформление (документ 1)

- Times New Roman 14 пт, полуторный интервал, отступ 1,25 см, поля 3,0 / 1,5 /
  2,0 / 2,0 см, выравнивание по ширине;
- титул и содержание — без номера страницы; страница с введением — третья,
  далее сквозная нумерация внизу по центру;
- заголовки глав — по центру, полужирным, ЗАГЛАВНЫМИ, с новой страницы;
  параграфы — с абзацного отступа, строчными;
- ссылки на источники — подстрочные сноски 10 пт (настоящие сноски Word);
  список источников — по ГОСТ Р 7.0.100-2018, 29 позиций;
- таблица: «Таблица N.» справа, заголовок по центру, источник под таблицей;
- формулы — по центру, номер в круглых скобках у правого края, расшифровка
  «где …» с новой строки.

Объём главы 1 считается отдельно (`build_ch1.py` печатает «страниц в главе 1»):
16 страниц при лимите 20. Список источников в лимит не входит.

## Модель (документ 2)

```
D_it = a + b·Brent_t + c·RUS_i + e·Y26_t + k·(RUS_i·Y26_t) + u_it
```

Метод — разность разностей (difference-in-differences) на панели «страна —
месяц»: Россия против Азербайджана, два равных полугодия «до» и «после»
снижения потолка цен до 44,1 долл./барр.

- `D_it` — дифференциал цены экспорта к Brent, долл./барр. (формула (17)
  главы 1); `Brent_t` — среднемесячная котировка; `RUS_i` = 1 для России;
  `Y26_t` = 1 с января 2026 г.;
- панель сбалансирована: 24 наблюдения, 12 месяцев (2025-01…06 и 2026-01…06),
  пропусков нет;
- главный коэффициент `k` = −10,28 долл./барр. (ошибка 1,81; p 1,8e−05;
  с группировкой по месяцу ошибка 1,73, p 9,8e−05); adjR² 0,961, σ 2,22;
- ручная разность разностей по средним даёт ровно то же число (−10,28);
- предпосылка параллельных трендов проверена: наклон разрыва в 2025 г.
  0,061 долл./барр. в месяц (p 0,773) — тренда нет;
- дата сдвига проверена перебором: 2026-01 (AIC 110,7) лучше 2026-02 (134,2)
  и 2026-03 (143,6);
- тест Чоу: Россия F = 46,40 (2 и 8 с.с., p 4,0e−05), Азербайджан F = 2,55
  (p 0,139) — асимметрия, на которую опирается глава 2;
- диагностика: Бройш–Паган p 0,118, Бройш–Годфри p 0,696, RESET p 0,216,
  Дарбин–Уотсон 1,77; Жарк–Бера p < 0,001 — поэтому дополнительно приведены
  HC1 и кластерные по месяцу ошибки;
- устойчивость: без 2026-01 k = −11,77 (p 1,1e−07), без Brent k = −10,28
  (p 7,8e−05), jackknife −9,38…−11,77;
- пересчёт в деньги (формула (2) документа): `L = k·Q·7,33/1000` — при
  экспорте 244,7 млн т потери 18,44 млрд долл. = 14,1 % нефтяного экспорта =
  31,1 % нефтегазовых доходов бюджета за 9 месяцев 2026 г.

Все числа в тексте документа формируются из `out/model.json`; ручных цифр нет,
поэтому `verify_docs.py` проверяет документ целиком.

## Данные

- `data/panel_prices.csv` — панель «страна — месяц» (24 строки, 12 месяцев ×
  2 страны): `month, country, price, brent, d_phase`.
- `data/brent-monthly.csv`, `data/wti-monthly.csv` — открытый ряд
  github.com/datasets/oil-prices (1987-05 — 2026-10), используется в полной
  версии работы.
- Помесячные цены Urals — информации Минэкономразвития России о среднем
  уровне цен (применяются для расчёта НДПИ); Azeri Light — справки об
  исполнении бюджета Азербайджана и Report.az / ABC.AZ; Brent — открытый
  помесячный ряд github.com/datasets/oil-prices. Каждая цифра панели имеет
  подстрочную сноску в документе 2.

## Проверки

```bash
python3 verify_docs.py                        # числа + источники, ожидаемый итог «ок»
DETAIL=1 python3 verify_layout.py out/*.docx  # разбивка по страницам
```

`verify_docs.py` печатает список источников реестра, которые не процитированы в
документе 1: это нормально — часть из них (методы оценивания, источники данных)
используется только в документе 2.
