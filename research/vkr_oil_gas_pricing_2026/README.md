# ВКР 2026: ценообразование на нефтегазовых рынках России и Азербайджана

Черновик выпускной квалификационной работы (бакалавриат).

**Тема:** «Особенности и перспективы изменения ценообразования на нефтегазовых
рынках (на примере России и Азербайджана)».

**Итоговый файл:** `out/VKR_2026_Tsenoobrazovanie_neftegaz_Rossiya_Azerbaijan.docx`

## Порядок сборки

```bash
cd research/vkr_oil_gas_pricing_2026
python3 analysis.py        # out/metrics.json
python3 build_figures.py   # figures/*.png
python3 build_docx.py      # out/VKR_...docx + out/blocks.json
```

Проверки (необязательно, но полезно перед сдачей):

```bash
python3 verify_numbers.py   # 0 нераспознанных токенов = все цифры прослеживаются
python3 verify_layout.py    # оценка числа страниц
```

`build_docx.py` завершается с ошибкой, если в тексте встретился ключ источника,
отсутствующий в `sources.py`, или если в списке литературы остался
непроцитированный источник.

## Оформление

- Times New Roman 14 пт, полуторный интервал, абзацный отступ 1,25 см;
- поля: левое 3,0 см, правое 1,5 см, верхнее и нижнее 2,0 см;
- выравнивание по ширине, заголовки разделов — с новой страницы;
- нумерация страниц — внизу по центру, титульный лист без номера;
- таблицы и рисунки с подписями по ГОСТ (подпись над таблицей, под рисунком);
- библиографические ссылки в тексте — `[n]`, список по ГОСТ Р 7.0.100-2018.

## Особенности реализации

- Каждая цифра в тексте берётся из `out/metrics.json`; «ручных» чисел в текстах
  глав нет, поэтому `verify_numbers.py` может проверить всю работу целиком.
- Ссылки на источники в исходниках пишутся как `[@@ключ]`, при сборке
  заменяются на порядковый номер в списке литературы.
- Номера страниц в содержании рассчитываются до сохранения документа
  (`verify_layout.page_map`) и подставляются в строки оглавления; при
  необходимости их можно обновить вручную после правок вёрстки.
- Оглавление оформлено как поле `TOC`: после открытия в Word его можно
  обновить (Ctrl+A, F9), чтобы получить автоматические номера страниц.
- Титульный лист содержит плейсхолдеры `[...]` — их нужно заменить на данные
  вуза, кафедры, автора и научного руководителя.


## Версия по методическим рекомендациям Финансового университета

Методичка (Соколова Е. С. и др., 2025) отличается от ГОСТ-варианта:

| Требование | Как реализовано |
|---|---|
| Ссылки подстрочные (сноски 10 пт) | `mr_engine.MRDoc` — настоящие сноски Word (`word/footnotes.xml`) |
| Заголовки глав по центру, полужирным, ЗАГЛАВНЫМИ | `MRDoc.h(level=1)` |
| Заголовки параграфов с абзацного отступа, строчными | `MRDoc.h(level=2)` |
| Интервалы 15 пт вокруг заголовков | параметры `before`/`after` |
| До 5 задач во введении | введение переписано, 3 задачи |
| Обязательные элементы введения | актуальность, цель, задачи, объект, предмет, степень изученности, теоретическая и информационная база, методы, значимость, структура |
| Таблицы: «Таблица N.» справа, заголовок по центру | `MRDoc.table(number=...)` |
| Формулы: расшифровка «где» с новой строки | `MRDoc.where([("P_i", "...")])` |

## Эконометрика

Данные: `data/brent-monthly.csv`, `data/wti-monthly.csv`
(github.com/datasets/oil-prices, 474 месяца, 1987-05 — 2026-10) +
помесячные цены Urals из `facts.py`.

```bash
python3 econometrics.py       # out/econometrics.json + out/econometrics_dump.txt
python3 build_econometrics_doc.py
# → out/VKR_2026_Ekonometricheskie_modeli.docx (~11 стр., 3 модели + приложения)
```

Семь реализованных спецификаций:

| Модель | Что оценивает | Ключевой результат |
|---|---|---|
| М1 | Brent ~ WTI + дамми институциональных сдвигов, n = 474 | связь бенчмарков не разрушается санкциями; шок Ормуза даёт +14,5 долл./барр. |
| М2 | дифференциал Urals–Brent, n = 17 | потолок 44,1 долл./барр. → +12,0 долл. к скидке (p < 0,001), R² = 0,53 |
| М2' | то же в логарифмах, 3 события | R² = 0,73; регламент ЕС по газу → +11,4 долл. |
| М3 | AR(1) логарифма Brent + ADF/коинтеграция | φ = 0,991; коинтеграция Brent–WTI (p = 0,005) |
| М4 (М6) | контрактная цена газа Азербайджана, уровни, n = 10 | рост Brent на 1 долл. → −0,08 долл./млн БТЕ; сдвиг 2026 г. +1,29 (p = 0,001) |
| М4' (М6) | то же по месячным приростам, n = 7 | слоп 0,0722 долл./млн БТЕ на 1 долл./барр. (R² = 0,96), 42 % энергопаритета |
| М5 (М7) | контрактная цена нефти Азербайджана, n = 3 | премия к Brent, регрессия невозможна — ограничение указано явно |

В документе также перечислены семь моделей-кандидатов (М1–М7), схема
размещения результатов по главам, таблица ограничений и приложения с
исходными рядами (в том числе контрактные цены Азербайджана: П.2–П.4).

### Данные по Азербайджану

Биржевых котировок азербайджанского газа нет (JODI, EIA и datasets/oil-prices
их не публикуют), поэтому используются **контрактные (таможенные) цены**:
объём и стоимость экспорта по декларациям ГТК АР (`facts_az.py`). Ряды
накопительные с начала года, поэтому цена месяца считается по приростам —
формула (16) первой главы. Отсечки, восстановленные расчётом, помечены в
поле `source`.
