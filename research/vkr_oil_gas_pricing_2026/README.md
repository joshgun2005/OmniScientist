# ВКР 2026: ценообразование на нефтегазовых рынках России и Азербайджана

**Тема:** «Особенности и перспективы изменения ценообразования на нефтегазовых
рынках (на примере России и Азербайджана)».

Работа собирается в виде двух самостоятельных файлов.

| Файл | Что внутри | Объём |
|---|---|---|
| `out/VKR_2026_Glava_1_Teoriya.docx` | титул, содержание, введение, глава 1, список источников (29) | 24 с., глава 1 — 16 с. из 20 |
| `out/VKR_2026_Ekonometricheskaya_model.docx` | единственная эконометрическая модель: постановка, данные, спецификация и правила расчёта, оценивание, результаты, перевод в деньги и рекомендации, инструменты | 14 с., 4 таблицы, 13 источников, 10 сносок |

## Порядок сборки

```bash
python3 analysis.py         # out/metrics.json  — реестр исходных показателей
python3 model.py            # out/model.json    — оценки модели
python3 build_ch1.py        # документ 1 (теория) + отчёт по страницам
python3 build_model_doc.py  # документ 2 (модель)
python3 verify_docs.py      # сверка чисел и источников в обоих документах
```

Зависимости: `python-docx`, `pandas`, `numpy`, `statsmodels`, `scipy`,
`matplotlib` (только для полной версии работы).

## Оформление (документ 1)

- Times New Roman 14 пт, полуторный интервал, отступ 1,25 см, поля 3,0 / 1,5 /
  2,0 / 2,0 см, выравнивание по ширине;
- титул и содержание — без номера страницы; страница с введением — третья,
  далее сквозная нумерация внизу по центру;
- заголовки глав — по центру, полужирным, ЗАГЛАВНЫМИ, с новой страницы;
  параграфы — с абзацного отступа, строчными;
- ссылки на источники — подстрочные сноски 10 пт (настоящие сноски Word);
  список источников — по ГОСТ Р 7.0.100-2018, 29 позиций;
- таблица: «Таблица N.» справа, заголовок по центру, источник под таблицей;
- формулы — по центру, номер в круглых скобках у правого края, расшифровка
  «где …» с новой строки.

Объём главы 1 считается отдельно (`build_ch1.py` печатает «страниц в главе 1»):
16 страниц при лимите 20. Список источников в лимит не входит.

## Модель (документ 2)

```
D_it = α + β·Brent_t + γ·RUS_i + δ·d_t + θ·(RUS_i·d_t) + u_it
```

- `D_it` — дифференциал средней цены экспорта к Brent, долл./барр.
  (формула (17) главы 1);
- панель «страна — месяц»: 29 наблюдений, 21 месяц (январь 2025 г. —
  октябрь 2026 г.), Россия — Urals (17 месяцев), Азербайджан — Azeri Light
  (12 месяцев); пропуски не заполняются;
- `d_t` = 1 с ноября 2025 г. — дата проверена перебором месяцев, а не задана
  априорно;
- оценивание — МНК, ошибки Ньюи–Уэста (2 лага); тест Чоу: классическая форма
  F = 26,55 (3 и 23 с.с.), форма уравнения (1) F = 41,32 (2 и 24 с.с.),
  внутри российской подвыборки F = 47,00 (2 и 13 с.с.);
- диагностика: Бройша–Пагана, Бройша–Годфри, Жарка–Бера, RESET,
  Дарбина–Уотсона, VIF; устойчивость: исключение выброса 2026-01 и
  сбалансированная подвыборка (θ = −11,03…−12,67, значима на 1 %);
- пересчёт в деньги: `L = |θ|·Q·k / 1000` — потери выручки от расширения
  скидки, далее сценарии при Brent 60/80/100/120 долл./барр.

Все числа в тексте документа формируются из `out/model.json`; ручных цифр нет,
поэтому `verify_docs.py` проверяет документ целиком.

## Данные

- `data/panel_prices.csv` — панель «страна — месяц»: `month, country, price, brent`.
- `data/brent-monthly.csv`, `data/wti-monthly.csv` — открытый ряд
  github.com/datasets/oil-prices (1987-05 — 2026-10), используется в полной
  версии работы.
- Помесячные цены Urals — публикации Минэкономразвития России; Azeri Light —
  таможенная статистика Азербайджана (стоимость / объём) и ABC.AZ; Brent —
  открытый помесячный ряд.

## Проверки

```bash
python3 verify_docs.py                        # числа + источники, ожидаемый итог «ок»
DETAIL=1 python3 verify_layout.py out/*.docx  # разбивка по страницам
```

`verify_docs.py` печатает список источников реестра, которые не процитированы в
документе 1: это нормально — часть из них (методы оценивания, источники данных)
используется только в документе 2.
