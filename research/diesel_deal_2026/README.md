1. Введение — проблема, исследовательский вопрос, гипотезы H1–H3
2. Теоретические основания и обзор литературы — 30 источников
3. Материалы и метод — источники, сценарный анализ, допущения, ограничения
4. Механизм и институциональная архитектура соглашения — генеральная лицензия OFAC № 135, коллизия с Public Law 117-109

6. Фискальный контур — выручка и бюджетный эффект
7. Институциональный контур — каналы риска и устойчивость

- Список литературы (30 позиций), англоязычная аннотация, сведения об авторе

## Трассируемость цифр

Все числовые утверждения рукописи проходят проверку `verify_numbers.py`:

```bash
python3 analysis.py        # расчёт контура -> out/metrics.json, таблицы, рисунки
python3 build_docx.py      # сборка DOCX + out/blocks.json
python3 build_pdf.py       # сборка PDF
python3 verify_numbers.py  # каждая цифра -> metrics.json или реестр статических фактов
```

Текущий результат проверки: 405 числовых токенов, 145 уникальных, 0 неатрибутированных.

## Ключевые результаты

- Программа: 4,80 млн т за шесть месяцев (октябрь 2026 — март 2027), в среднем 0,80 млн т/мес = 2,67 % международной торговли дизелем
- Покрытие мирового дефицита: 5,0–7,5 % (окт.), 8,3–12,5 % (нояб.), 16,7–25,0 % (дек.)
- Валовая выручка: 4,32–6,72 млрд долл. (353,3–549,6 млрд руб.)
- Бюджетный эффект при k = 0,25–0,35: 137,4–192,4 млрд руб. = 2,6–3,7 % дефицита за январь–сентябрь 2026 г.
- Институциональная устойчивость: низкая (коллизия лицензии со статутом, срок до 07.04.2027, смена контроля над Конгрессом 03.11.2026)

## Ограничения

Коммерческие условия контрактов не раскрываются; часть объёмов могла быть перенаправлена в третьи страны; оценка мирового дефицита (4–6 млн т/мес) экспертная. Эти ограничения зафиксированы в разделе 3 и в заключении.
